# ONG Esperança

Projeto de desenvolvimento front-end desenvolvido para a ONG Esperança, uma organização fictícia voltada para ações sociais, voluntariado, doações e campanhas de solidariedade.

O projeto foi desenvolvido como parte da atividade prática de desenvolvimento front-end, utilizando HTML5, CSS3 e JavaScript, com foco em organização, responsividade, acessibilidade, navegação e interação com o usuário.

---

## 📌 Sobre o projeto

A plataforma da ONG Esperança tem como objetivo apresentar a organização, divulgar seus projetos sociais e permitir o cadastro de pessoas interessadas em atuar como voluntárias.

A aplicação possui uma interface responsiva, adaptada para diferentes tamanhos de tela, além de recursos de navegação, validação de formulário, máscaras de entrada e armazenamento dos dados cadastrados no navegador.

---

## 🎯 Objetivos

- Apresentar a ONG Esperança e sua missão;
- Divulgar projetos e ações sociais;
- Incentivar doações e voluntariado;
- Divulgar campanhas;
- Permitir o cadastro de voluntários;
- Oferecer uma experiência de navegação responsiva;
- Aplicar boas práticas de HTML, CSS e JavaScript;
- Implementar recursos básicos de acessibilidade.

---

## 🛠️ Tecnologias utilizadas

### HTML5

Utilizado para estruturar o conteúdo da aplicação, utilizando elementos semânticos, formulários e recursos nativos de validação.

### CSS3

Utilizado para a estilização da interface e implementação do Design System, incluindo:

- Variáveis CSS;
- Cores padronizadas;
- Tipografia;
- Espaçamentos;
- CSS Grid;
- Flexbox;
- Media Queries;
- Transições;
- Layout responsivo.

### JavaScript

Utilizado para implementar a interação e o comportamento da aplicação, incluindo:

- Navegação dinâmica;
- Manipulação do DOM;
- Eventos de clique;
- Eventos de formulário;
- Validação dos campos;
- Máscaras de CPF, telefone e CEP;
- Armazenamento e recuperação dos dados.

### Git e GitHub

Utilizados para controle de versão, organização do desenvolvimento e gerenciamento das alterações do projeto.
